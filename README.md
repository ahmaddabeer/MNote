# MNote – Notes App 📝

MNote is a simple Android Notes application that allows users to create, view, edit, and delete their personal notes.

## ✨ Features

- Add new notes
- View all saved notes
- View note details
- Edit existing notes
- Delete notes
- Save notes locally using Room Database

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose
- **Design:** Material 3
- **Database:** Room Database
- **Architecture:** MVVM
- **Dependency Injection:** Hilt (Dagger)
- **Asynchronous Programming:** Kotlin Coroutines & Flow

## 📱 Screens

- Home Screen
- Add Note Screen
- Note Details Screen
- Edit Note Screen
