# 📝 MNote – Android Notes App

**MNote** is a modern Android Notes application developed as part of an internship task. It allows users to create, manage, organize, and maintain their personal notes with a simple and user-friendly interface.

The application is built using modern Android development technologies, following the MVVM architecture and local data persistence with Room Database.

## ✨ Features

- **Create Notes:** Easily create and save new notes.
- **View Notes:** Browse all saved notes from the home screen.
- **Note Details:** View the complete content of individual notes.
- **Edit Notes:** Update previously saved notes.
- **Delete Notes:** Remove unwanted notes.
- **Local Storage:** Persist notes locally using Room Database.
- **Reactive UI:** Manage UI updates using Kotlin Flow and Coroutines.

## 🏗️ Architecture

MNote follows the **MVVM (Model-View-ViewModel)** architecture to maintain separation of concerns and improve code organization.

- **Presentation Layer:** Compose screens and UI components.
- **ViewModel Layer:** Handles UI state and business logic.
- **Data Layer:** Manages note data and database operations.
- **Room Database:** Stores notes locally on the device.



## ⚙️ Installation & Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/ahmaddabeer/MNote
   ```

2. Open the project in Android Studio.
3. Allow Gradle to sync dependencies.
4. Run the application on an Android emulator or physical device.
